# Dev Docs Templates

These templates help you create structured documentation for different task types.

## Available Templates

- **feature-plan.template.md** - For new features
- **bugfix-plan.template.md** - For bug fixes
- **refactor-plan.template.md** - For refactoring tasks
- **context.template.md** - Session context tracking
- **tasks.template.md** - Task checklists

## Usage

1. Copy the appropriate template to `dev/active/your-task-name/`
2. Rename it (remove `.template` from filename)
3. Fill in the sections
4. Update frequently during development

See: ~/dev/README.md for the Dev Docs Pattern guide
